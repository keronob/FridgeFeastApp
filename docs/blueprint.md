# **App Name**: Fridge Feast

## Core Features:

- Ingredient Input: Simple form to input available ingredients.
- Recipe Generation: Generates recipes based on entered ingredients using a generative AI model. The AI model will act as a tool, using reasoning to determine whether or not certain ingredients are necessary for a recipe to work or not. 
- Recipe Display: Displays the generated recipe with instructions and required cooking time.
- Recipe Saving: Allows users to save generated recipes locally (e.g., in local storage).

## Style Guidelines:

- Primary color: Shades of green to evoke freshness and natural ingredients.
- Secondary color: Off-white or light gray for backgrounds to ensure readability.
- Accent: A vibrant yellow-green (#BFFF00) for interactive elements and highlights.
- Clean and simple layout with a focus on readability.
- Use simple, line-based icons for ingredients and recipe steps.

## Original User Request:
A simple recipe maker that generates recipes based on the ingredients I have in my fridge. Simple UI, green color scheme.
